NETA Frontend v2 — visual prototype

This version includes:
- Real Matrix rain animation (canvas)
- NETA wireframe globe SVG asset
- NETA logo SVG asset
- Real holder data from the current Juno + Osmosis snapshot
- Working address lookup
- Top 10 ranking
- Responsive CSS
- No wallet connection

HOW TO RUN
1. Extract the ZIP completely.
2. Keep the folder structure intact, especially /assets.
3. Double-click index.html.

If it still appears as plain HTML, verify that styles.css sits in the same folder as index.html.
